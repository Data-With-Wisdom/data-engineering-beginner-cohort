## Assignment 7.1: End-to-End Capstone Project

### Task
Build a small data engineering project that shows the full learning journey from the course.

### Requirements
- Use a realistic dataset or a simple sample dataset
- Clean and transform the data using Python and Pandas
- Create a simple output such as a CSV, JSON file, or database table
- Write at least 3 SQL queries that answer business questions
- Add a `README.md` that explains the project clearly
- Push the project to GitHub

### Suggested deliverables
- one Python script or notebook
- one cleaned output file
- one SQL file or query list
- a short reflection explaining what was learned

### Success looks like
The project should feel complete, explainable, and professional enough to share with others.
