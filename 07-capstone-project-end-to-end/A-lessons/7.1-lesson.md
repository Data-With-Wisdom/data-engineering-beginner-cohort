# Lesson 7.1: Capstone Project Overview

## Why this matters
The capstone is where students connect all the earlier ideas into one practical project. Instead of learning isolated skills, they now see how data engineering work comes together.

## What the capstone should include
A strong beginner capstone can include:
- a dataset in CSV or JSON format
- a Python script for cleaning or transforming data
- a simple output file or database table
- at least a few SQL queries answering business questions
- a README explaining the project and how to run it

## Suggested project idea
Students can build a small sales or customer analytics project that:
1. loads raw data
2. cleans it with Pandas
3. creates a cleaner output table
4. answers business questions using SQL
5. documents the full process in GitHub

## Teaching focus
The lesson should help students understand the project as a story:
- what problem is being solved
- what data is being used
- how the pipeline works
- how the final result is shared

## Key takeaway
The capstone is not about perfection. It is about showing that a student can take a messy data problem and turn it into a structured, explainable solution.
