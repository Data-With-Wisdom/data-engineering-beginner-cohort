# Module 7: Capstone Project (Week 7)

This module brings together everything students have learned so far in one end-to-end project.

## Project goal
Students will build a small but realistic data engineering workflow that includes:
- data loading
- data cleaning and transformation
- basic storage or output
- documentation
- simple presentation of the work

## What students should demonstrate
- Python for data processing
- SQL for answering business questions
- Pandas for transformation
- Git and GitHub for sharing work
- clear communication through a README and explanation
