## Activity 6.1: Push a Project to GitHub

### Goal
Practice turning a local project into a professional GitHub repository.

### Instructions
1. Create a simple folder for a project.
2. Add a Python script and a small dataset or sample file.
3. Create a `README.md` explaining the project.
4. Initialize Git in the folder.
5. Add and commit the files.
6. Create a GitHub repository and push the project.

### Reflection questions
- What did you include in the README?
- What was easy or difficult about pushing the project?
- How would you make the repository easier for someone else to use?
