# Module 6: Working Like a Professional + Intro to Big Data (Week 6)

This module helps students move from learning tools to building professional, shareable data projects.

## What students will learn
- How to use Git and GitHub for version control
- How to structure a repository and write a good README
- How to manage Python dependencies and environments
- Why data grows beyond the limits of a single laptop
- When a team might choose Pandas, Spark, or other tools

## Teaching flow
- Start with practical collaboration skills
- Connect those skills to real-world data engineering workflows
- Introduce big data thinking in a simple and clear way
