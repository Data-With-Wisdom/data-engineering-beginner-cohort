# Lesson 6.3: requirements.txt and Environment Files

## Why this matters
When you share Python projects, other people need to know which packages are required. Without a dependency list, the project may fail on another machine.

## What is requirements.txt?
The file `requirements.txt` lists the Python packages needed to run a project.

Example:
```text
pandas==2.2.2
sqlalchemy==2.0.31
```

## How students use it
A learner can install everything in one step:
```bash
pip install -r requirements.txt
```

## Environment files
Some projects also include `.env` files to store settings such as database credentials or API keys.

Important rule:
- never commit secrets to GitHub
- keep sensitive values in local environment files or secret managers

## Why this matters in data engineering
Data engineering projects often depend on database drivers, file parsers, and cloud libraries. A clean environment file makes reproduction easier.

## Key takeaway
Good dependency management makes a project repeatable, professional, and easier to run for others.
