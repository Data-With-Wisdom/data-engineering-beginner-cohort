# Lesson 6.6: NiFi, Airflow, Kafka, and Cloud Overview

## Why this matters
Modern data engineering teams use many tools. Each tool solves a different part of the workflow, from moving data to scheduling jobs and processing streams.

## Apache NiFi
NiFi is used to move and transform data between systems. It is useful when data must flow from one source to another in a visual and manageable way.

## Apache Airflow
Airflow helps schedule and monitor data pipelines. A team can define workflows that run every day, every hour, or when a trigger occurs.

## Apache Kafka
Kafka is a system for handling streams of events. It is often used when data arrives continuously and needs to be processed in near real time.

## Cloud platforms
Cloud providers offer managed services that make it easier to run these systems. They help teams reduce infrastructure maintenance and scale more quickly.

## Key takeaway
Students do not need to master every tool yet. The goal is to recognize what each tool is for and understand the broader ecosystem.
