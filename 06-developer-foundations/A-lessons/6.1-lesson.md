# Lesson 6.1: Git and GitHub Basics

## Why this matters
A data engineer rarely works alone. Projects are shared, updated, reviewed, and improved over time. Git helps you track changes safely, while GitHub helps you share your work with others.

## What is Git?
Git is a version control system. It keeps a history of your project so you can:
- save progress safely
- return to an older version if needed
- work on features without breaking the main project

## Common Git commands
```bash
git init
git status
git add .
git commit -m "Add first version"
git push origin main
```

## What GitHub gives you
GitHub adds a web-based home for your project where you can:
- store your code online
- share your work with classmates or recruiters
- collaborate with teammates
- show your portfolio publicly

## Simple example
Imagine you are building a data cleaning script. After every improvement, you commit the change. If something breaks later, you can compare versions and fix it quickly.

## Key takeaway
Git and GitHub are not just for software developers. Data engineers use them to keep pipelines, scripts, and documentation organized and reproducible.
