# Lesson 6.4: Why Data Gets Big

## Why this matters
Data starts small, but it can grow very quickly. A simple CSV file can become millions of rows, and a small script may stop being enough.

## What makes data “big”
Data becomes difficult to handle when one or more of these increase:
- volume: too many rows
- velocity: data arrives very quickly
- variety: data comes in many formats

## Real-world examples
- a delivery app recording every order and location update
- a bank tracking every transaction
- a website logging user clicks every second

## Why this challenge matters
A laptop may handle a small dataset easily, but a large dataset may require better storage, faster processing, and distributed tools.

## Key takeaway
Big data is not only about file size. It is about the complexity and speed of processing information.
