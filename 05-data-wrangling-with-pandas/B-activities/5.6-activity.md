## Activity 5.6

**Task:** Merge a lookup table into the employees dataset.

```python
import pandas as pd

df = pd.read_csv("datasets/employees.csv")
df["Department"] = df["Department"].fillna("Unknown")
```

1) Create the lookup table:

```python
dept_df = pd.DataFrame({
    "Department": ["Engineering", "HR", "Finance", "Unknown"],
    "Location": ["Lagos", "Abuja", "Port Harcourt", "Unknown"]
})
```

2) Merge and print:

```python
merged = pd.merge(df, dept_df, on="Department", how="left")
print(merged)
```
