## Activity 5.4

**Task:** Clean the employees dataset.

```python
import pandas as pd

df = pd.read_csv("datasets/employees.csv")
```

1) Find missing values per column:

```python
print(df.isnull().sum())
```

2) Fix the `Age` column (replace `"thirty"`, convert type, fill missing):

```python
df["Age"] = df["Age"].replace("thirty", 30)
df["Age"] = df["Age"].astype(float)
df["Age"] = df["Age"].fillna(df["Age"].mean())
```

3) Fill missing `Salary` with the average salary:

```python
df["Salary"] = df["Salary"].fillna(df["Salary"].mean())
```

4) Fill missing `Department` with `"Unknown"`:

```python
df["Department"] = df["Department"].fillna("Unknown")
```

5) Print the cleaned DataFrame and confirm nulls are gone:

```python
print(df)
print(df.isnull().sum())
```
