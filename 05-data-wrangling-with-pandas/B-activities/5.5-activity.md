## Activity 5.5

**Task:** Transform and aggregate the cleaned dataset.

```python
import pandas as pd

df = pd.read_csv("datasets/employees.csv")

df["Age"] = df["Age"].replace("thirty", 30).astype(float)
df["Age"] = df["Age"].fillna(df["Age"].mean())
df["Salary"] = df["Salary"].fillna(df["Salary"].mean())
df["Department"] = df["Department"].fillna("Unknown")
```

1) Create `Salary_After_Tax`:

```python
df["Salary_After_Tax"] = df["Salary"] * 0.8
```

2) Filter employees older than 25:

```python
print(df[df["Age"] > 25])
```

3) Average salary per department:

```python
print(df.groupby("Department")["Salary"].mean())
```

4) Sort by salary descending:

```python
print(df.sort_values(by="Salary", ascending=False))
```
