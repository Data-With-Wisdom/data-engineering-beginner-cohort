# Lesson 5.8: Pandas vs SQL (and Common Mistakes)

## Pandas vs SQL

| SQL      | Pandas             |
| -------- | ------------------ |
| SELECT * | `df`               |
| WHERE    | `df[df["Age"] > 25]` |
| GROUP BY | `df.groupby()`     |
| JOIN     | `pd.merge()`       |

---

## Common mistakes

### 1) Not saving changes

```python
df.dropna()
```

Correct:

```python
df = df.dropna()
```

---

### 2) Wrong column name / case

```python
df["age"]  # not the same as "Age"
```

---

### 3) Wrong data type

For example:
- `"30"` (string) instead of `30` (number)

---

## Key takeaway

Pandas helps you:
- Clean data
- Transform data
- Analyze data

In real-world data engineering, a large portion of time is spent cleaning and preparing data.
