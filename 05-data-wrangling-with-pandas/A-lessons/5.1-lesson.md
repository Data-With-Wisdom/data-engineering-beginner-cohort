# Lesson 5.1: DataFrames and Series

## What is Pandas?

Pandas is a Python library used to work with **structured data** (tables like Excel sheets or database tables).

In data engineering, most raw data ends up in rows and columns, and Pandas helps you:
- Load data (CSV, JSON, databases)
- Inspect it quickly
- Clean and transform it
- Analyze it

---

## Dataset for this module

- `05-data-wrangling-with-pandas/datasets/employees.csv`

---

## Series (one column)

A **Series** is a single column of data.

```python
import pandas as pd

data = pd.Series([10, 20, 30])
print(data)
```

Think of a Series as:
- One column in Excel
- A list with an index (labels)

---

## DataFrame (table)

A **DataFrame** is a table with rows and columns.

```python
import pandas as pd

df = pd.read_csv("datasets/employees.csv")
print(df)
```

Think of a DataFrame as:
- An Excel sheet
- A database table
