# Lesson 5.5: Transformations and Aggregations

---

## Create a new column

```python
df["Salary_After_Tax"] = df["Salary"] * 0.8
```

---

## Filter rows

```python
df[df["Age"] > 25]
```

---

## Group and aggregate

```python
df.groupby("Department")["Salary"].mean()
```

---

## Sort data

```python
df.sort_values(by="Salary", ascending=False)
```
