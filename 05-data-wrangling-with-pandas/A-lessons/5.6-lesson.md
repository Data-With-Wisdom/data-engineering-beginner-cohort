# Lesson 5.6: Merging and Joining

Sometimes data is split into multiple tables/files, and you need to combine them.

---

## Example lookup table

```python
import pandas as pd

dept_df = pd.DataFrame({
    "Department": ["Engineering", "HR", "Finance"],
    "Location": ["Lagos", "Abuja", "Port Harcourt"]
})
```

---

## Merge

```python
df = pd.merge(df, dept_df, on="Department", how="left")
```

This adds the `Location` column to your employees data.
