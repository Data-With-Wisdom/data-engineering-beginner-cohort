# Lesson 5.2: Loading Data

In real-world scenarios, you rarely create data manually—you load it from files or databases.

---

## Load a CSV file

```python
import pandas as pd

df = pd.read_csv("datasets/employees.csv")
```

---

## Load a JSON file (same data)

```python
import pandas as pd

df = pd.read_json("datasets/employees.json")
```

---

## Load data from PostgreSQL

In real-world applications, data is often stored in databases like PostgreSQL. Instead of downloading files manually, you connect directly to the database.

### Step 1: Install the library

```bash
pip install psycopg2-binary
```

### Step 2: Connect

```python
import psycopg2

conn = psycopg2.connect(
    host="localhost",
    database="your_database",
    user="your_username",
    password="your_password"
)
```

### Step 3: Query into a DataFrame

```python
import pandas as pd

query = "SELECT * FROM employees"
df = pd.read_sql(query, conn)
```

### What is happening?

- Connect to the database
- Run a SQL query
- Convert the result into a DataFrame

### Best practice

Always select only the columns you need:

```python
query = "SELECT name, age, department, salary FROM employees"
```

### Close the connection

```python
conn.close()
```
