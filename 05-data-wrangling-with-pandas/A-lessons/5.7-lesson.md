# Lesson 5.7: Exporting Data

After cleaning and transforming data, you often need to save or load it into another system.

---

## Save cleaned data to CSV

```python
df.to_csv("clean_employees.csv", index=False)
```

---

## Save to Excel

```python
df.to_excel("clean_employees.xlsx", index=False)
```

---

## Write cleaned data to PostgreSQL

In real-world ETL pipelines, you can load cleaned data back into PostgreSQL so it can be used by dashboards, other teams, or downstream jobs.

### Install SQLAlchemy

```bash
pip install sqlalchemy
```

### Create an engine

```python
from sqlalchemy import create_engine

engine = create_engine(
    "postgresql+psycopg2://your_username:your_password@localhost:5432/your_database"
)
```

### Write the DataFrame

```python
df.to_sql(
    "clean_employees",
    engine,
    if_exists="replace",  # "replace", "append", or "fail"
    index=False
)
```

### Verify quickly

```python
import pandas as pd

pd.read_sql("SELECT * FROM clean_employees LIMIT 5", engine)
```
