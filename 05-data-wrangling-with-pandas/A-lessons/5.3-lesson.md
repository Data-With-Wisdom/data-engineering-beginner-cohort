# Lesson 5.3: Inspecting Data

Before you transform data, you must understand it.

---

## View the data

```python
df.head()
df.tail()
```

Use these to quickly check what the dataset looks like.

---

## Check structure and types

```python
df.info()
```

This helps you notice:
- Missing values (for example: `Age`, `Salary`, `Department`)
- Wrong data types (for example: `Age = "thirty"`)

---

## Summary statistics

```python
df.describe()
```

Works for numeric columns by default.
