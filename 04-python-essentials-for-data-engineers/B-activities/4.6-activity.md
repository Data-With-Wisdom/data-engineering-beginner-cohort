## Practice Exercises 

### **Exercise 1: Read and Filter CSV**

Create `customers.csv`:
```csv
customer_id,name,city,total_spent
1,Ahmed Hassan,Lagos,50000
2,Chioma Obi,Abuja,75000
3,Emeka Nwosu,Lagos,30000
```

**Task:** Read the file and print only Lagos customers.

**Solution:**
```python
import csv

with open('customers.csv', 'r') as file:
    reader = csv.DictReader(file)
    
    for row in reader:
        if row['city'] == 'Lagos':
            print(f"{row['name']}: ₦{row['total_spent']}")
```

### **Exercise 2: Write CSV from Data**

**Task:** Create a CSV file with product data.
```python
import csv

products = [
    {'product_id': 1, 'name': 'Laptop', 'price': 500000},
    {'product_id': 2, 'name': 'Mouse', 'price': 5000},
    {'product_id': 3, 'name': 'Keyboard', 'price': 15000}
]

with open('products.csv', 'w', newline='') as file:
    fieldnames = ['product_id', 'name', 'price']
    writer = csv.DictWriter(file, fieldnames=fieldnames)
    
    writer.writeheader()
    writer.writerows(products)

print("Products CSV created!")
```

### **Exercise 3: Read JSON and Calculate**

Create `orders.json`:
```json
[
  {"order_id": 1, "amount": 5000},
  {"order_id": 2, "amount": 7500},
  {"order_id": 3, "amount": 3000}
]
```

**Task:** Calculate total revenue.

**Solution:**
```python
import json

with open('orders.json', 'r') as file:
    orders = json.load(file)

total = sum(order['amount'] for order in orders)
print(f"Total revenue: ₦{total}")  # ₦15500
```

### **Exercise 4: CSV to JSON Conversion**

**Task:** Convert your products CSV to JSON.
```python
import csv
import json

# Read CSV
with open('products.csv', 'r') as csv_file:
    products = list(csv.DictReader(csv_file))

# Write JSON
with open('products.json', 'w') as json_file:
    json.dump(products, json_file, indent=2)

print("Converted to JSON!")
```
