# Lesson 4.7: String Manipulation

## Why String Manipulation Matters

**Data engineers constantly clean messy text data:**
- 🧹 Remove extra spaces
- 🔤 Standardize case (uppercase/lowercase)
- ✂️ Extract parts of strings (email domains, area codes)
- 🔄 Replace values
- ✅ Validate formats

**Common scenarios:**
- Customer names with inconsistent capitalization
- Phone numbers in different formats
- Emails with extra spaces
- Addresses needing standardization

---

## Basic String Operations

### **Length**
```python
text = "Hello"
print(len(text))  # 5
```

---

### **Concatenation (Joining)**
```python
first_name = "Ahmed"
last_name = "Hassan"

# Method 1: +
full_name = first_name + " " + last_name
print(full_name)  # Ahmed Hassan

# Method 2: f-strings (better)
full_name = f"{first_name} {last_name}"
print(full_name)  # Ahmed Hassan
```

---

### **Repetition**
```python
print("Ha" * 3)  # HaHaHa
print("=" * 20)  # ====================
```

---

### **Accessing Characters (Indexing)**
```python
text = "Python"
print(text[0])   # P (first character)
print(text[1])   # y
print(text[-1])  # n (last character)
print(text[-2])  # o (second to last)
```

---

### **Slicing**
```python
text = "Data Engineering"

print(text[0:4])   # "Data" (characters 0-3)
print(text[5:])    # "Engineering" (from 5 to end)
print(text[:4])    # "Data" (from start to 3)
print(text[-11:])  # "Engineering" (last 11 characters)
```

## String Methods

**Methods are functions that belong to strings.**

### **Case Conversion**
```python
text = "Ahmed Hassan"

print(text.upper())      # "AHMED HASSAN"
print(text.lower())      # "ahmed hassan"
print(text.title())      # "Ahmed Hassan" (capitalize each word)
print(text.capitalize()) # "Ahmed hassan" (capitalize first letter only)

# Case-insensitive comparison
email1 = "Ahmed@Email.com"
email2 = "ahmed@email.com"
print(email1.lower() == email2.lower())  # True
```

---

### **Whitespace Removal**
```python
text = "  Ahmed Hassan  "

print(text.strip())   # "Ahmed Hassan" (remove both sides)
print(text.lstrip())  # "Ahmed Hassan  " (remove left)
print(text.rstrip())  # "  Ahmed Hassan" (remove right)

# Real use case: cleaning user input
name = input("Enter name: ").strip()  # Removes accidental spaces
```

---

### **Replace**
```python
text = "Hello World"
new_text = text.replace("World", "Python")
print(new_text)  # "Hello Python"

# Replace multiple occurrences
phone = "080-1234-5678"
cleaned = phone.replace("-", "")
print(cleaned)  # "08012345678"

# Chain multiple replacements
text = "Hello, World! How are you?"
cleaned = text.replace(",", "").replace("!", "").replace("?", "")
print(cleaned)  # "Hello World How are you"
```

---

### **Split (String to List)**
```python
text = "Lagos,Abuja,Port Harcourt"
cities = text.split(",")
print(cities)  # ['Lagos', 'Abuja', 'Port Harcourt']

# Split by spaces
sentence = "Data engineering is fun"
words = sentence.split()
print(words)  # ['Data', 'engineering', 'is', 'fun']

# Real use case: CSV parsing
csv_line = "Ahmed Hassan,ahmed@email.com,Lagos"
fields = csv_line.split(",")
name, email, city = fields
print(name)  # "Ahmed Hassan"
```

---

### **Join (List to String)**
```python
words = ["Data", "engineering", "is", "fun"]
sentence = " ".join(words)
print(sentence)  # "Data engineering is fun"

# Join with different separator
cities = ["Lagos", "Abuja", "Kano"]
csv_line = ",".join(cities)
print(csv_line)  # "Lagos,Abuja,Kano"
```

---

### **Find and Check**
```python
email = "ahmed@email.com"

# Check if substring exists
print("@" in email)  # True
print("gmail" in email)  # False

# Find position
print(email.find("@"))  # 5 (index where @ appears)
print(email.find("xyz"))  # -1 (not found)

# Check start/end
print(email.startswith("ahmed"))  # True
print(email.endswith(".com"))  # True
```

---

### **Count**
```python
text = "hello world hello"
print(text.count("hello"))  # 2
print(text.count("o"))  # 3
```

## String Validation

**Check if string matches a pattern:**
```python
text = "12345"
print(text.isdigit())  # True (all digits)

text = "Ahmed"
print(text.isalpha())  # True (all letters)

text = "Ahmed123"
print(text.isalnum())  # True (letters + digits)

text = "  "
print(text.isspace())  # True (all whitespace)
```

## Real-World Data Cleaning Examples

### **Example 1: Clean Customer Names**
```python
def clean_name(name):
    # Remove extra spaces
    cleaned = name.strip()
    # Capitalize properly
    cleaned = cleaned.title()
    return cleaned

# Test
names = ["  ahmed hassan  ", "CHIOMA OBI", "emeka nwosu"]
for name in names:
    print(clean_name(name))

# Output:
# Ahmed Hassan
# Chioma Obi
# Emeka Nwosu
```

---

### **Example 2: Clean Phone Numbers**
```python
def clean_phone(phone):
    # Remove all non-digit characters
    cleaned = ""
    for char in phone:
        if char.isdigit():
            cleaned += char
    return cleaned

# Alternative using replace
def clean_phone_v2(phone):
    return phone.replace(" ", "").replace("-", "").replace("(", "").replace(")", "")

# Test
phones = ["080-1234-5678", "070 9876 5432", "(081) 234-5678"]
for phone in phones:
    print(clean_phone(phone))

# Output:
# 08012345678
# 07098765432
# 08123456789
```

---

### **Example 3: Extract Email Domain**
```python
def get_email_domain(email):
    if "@" in email:
        parts = email.split("@")
        return parts[1]
    return None

# Test
emails = ["ahmed@gmail.com", "chioma@yahoo.com", "emeka@company.ng"]
for email in emails:
    domain = get_email_domain(email)
    print(f"{email} → {domain}")

# Output:
# ahmed@gmail.com → gmail.com
# chioma@yahoo.com → yahoo.com
# emeka@company.ng → company.ng
```

---

### **Example 4: Validate Email (Simple)**
```python
def is_valid_email(email):
    # Basic validation
    email = email.strip().lower()
    if "@" not in email:
        return False
    if "." not in email:
        return False
    if email.startswith("@") or email.endswith("@"):
        return False
    return True

# Test
emails = ["ahmed@email.com", "invalid-email", "@bad.com", "good@email.co"]
for email in emails:
    status = "Valid" if is_valid_email(email) else "Invalid"
    print(f"{email}: {status}")
```

---

### **Example 5: Parse CSV Line**
```python
def parse_csv_line(line):
    # Split by comma and clean each field
    fields = line.split(",")
    cleaned_fields = [field.strip() for field in fields]
    return cleaned_fields

# Test
csv_line = "  Ahmed Hassan  ,  ahmed@email.com  ,  Lagos  "
parsed = parse_csv_line(csv_line)
print(parsed)  # ['Ahmed Hassan', 'ahmed@email.com', 'Lagos']
```

## String Formatting

### **Old Way (% formatting)**
```python
name = "Ahmed"
age = 28
print("My name is %s and I am %d years old" % (name, age))
```

---

### **Better Way (.format())**
```python
name = "Ahmed"
age = 28
print("My name is {} and I am {} years old".format(name, age))
```

---

### **Best Way (f-strings) - Python 3.6+**
```python
name = "Ahmed"
age = 28
print(f"My name is {name} and I am {age} years old")

# With calculations
price = 1000
print(f"Price with VAT: ₦{price * 1.075}")

# With formatting
pi = 3.14159
print(f"Pi rounded: {pi:.2f}")  # Pi rounded: 3.14
```

## Key Takeaways

✅ **Case conversion** - `.upper()`, `.lower()`, `.title()`  
✅ **Whitespace** - `.strip()`, `.lstrip()`, `.rstrip()`  
✅ **Replace** - `.replace(old, new)`  
✅ **Split/Join** - `.split()` (string → list), `.join()` (list → string)  
✅ **Find** - `in`, `.find()`, `.startswith()`, `.endswith()`  
✅ **Validation** - `.isdigit()`, `.isalpha()`, `.isalnum()`  
✅ **f-strings** - Best way to format strings: `f"{variable}"`
