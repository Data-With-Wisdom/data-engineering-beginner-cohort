# Lesson 4.3: Data Structures (Lists, Dictionaries, Tuples, Sets)

## What are Data Structures?

**Data structures are containers that hold multiple pieces of data.**

**Why we need them:**
- Store collections of data (like a column in a spreadsheet)
- Organize related information together
- Process multiple items efficiently

**Think of them as:**
- **List** = Shopping list (ordered items)
- **Dictionary** = Phone book (name → phone number)
- **Tuple** = GPS coordinates (fixed values that don't change)
- **Set** 

---

## Lists

**A list stores multiple items in order.**

**Think of a list as:** A column in Excel or a shopping list.

### **Creating Lists**
```python
# Empty list
customers = []

# List of strings
cities = ["Lagos", "Abuja", "Port Harcourt"]

# List of numbers
prices = [1000, 2500, 500, 7500]

# Mixed types (not common, but allowed)
mixed = ["Ahmed", 25, True, 99.99]
```

---

### **Accessing List Items (Indexing)**

**Lists are indexed starting from 0:**
```python
cities = ["Lagos", "Abuja", "Port Harcourt"]

print(cities[0])  # "Lagos" (first item)
print(cities[1])  # "Abuja" (second item)
print(cities[2])  # "Port Harcourt" (third item)
```

**Negative indexing (from the end):**
```python
print(cities[-1])  # "Port Harcourt" (last item)
print(cities[-2])  # "Abuja" (second to last)
```

---

### **Common List Operations**

**Length:**
```python
cities = ["Lagos", "Abuja", "Port Harcourt"]
print(len(cities))  # 3
```

**Add items:**
```python
cities = ["Lagos"]
cities.append("Abuja")  # Add to end
print(cities)  # ["Lagos", "Abuja"]

cities.insert(0, "Kano")  # Add at position 0
print(cities)  # ["Kano", "Lagos", "Abuja"]
```

**Remove items:**
```python
cities = ["Lagos", "Abuja", "Kano"]
cities.remove("Abuja")  # Remove by value
print(cities)  # ["Lagos", "Kano"]

last_city = cities.pop()  # Remove and return last item
print(last_city)  # "Kano"
print(cities)  # ["Lagos"]
```

**Check if item exists:**
```python
cities = ["Lagos", "Abuja"]
print("Lagos" in cities)  # True
print("Kano" in cities)   # False
```

---

### **Slicing Lists**

**Get a portion of a list:**
```python
numbers = [10, 20, 30, 40, 50]

print(numbers[1:3])   # [20, 30] (items at index 1 and 2)
print(numbers[:3])    # [10, 20, 30] (first 3 items)
print(numbers[2:])    # [30, 40, 50] (from index 2 to end)
print(numbers[-2:])   # [40, 50] (last 2 items)
```

---

### **List Methods (Common)**
```python
prices = [1000, 500, 2500, 500, 7500]

# Sort
prices.sort()
print(prices)  # [500, 500, 1000, 2500, 7500]

# Reverse
prices.reverse()
print(prices)  # [7500, 2500, 1000, 500, 500]

# Count occurrences
print(prices.count(500))  # 2

# Find index
print(prices.index(1000))  # 2
```

---

### **Looping Through Lists**
```python
cities = ["Lagos", "Abuja", "Port Harcourt"]

# Method 1: Simple loop
for city in cities:
    print(city)

# Method 2: With index
for i in range(len(cities)):
    print(f"{i}: {cities[i]}")

# Output:
# 0: Lagos
# 1: Abuja
# 2: Port Harcourt

# Method 3: Using enumerate (best)
for index, city in enumerate(cities):
    print(f"{index}: {city}")
```

## Dictionaries

**A dictionary stores key-value pairs.**

**Think of it as:** A phone book (name → phone number) or a real dictionary (word → definition).

### **Creating Dictionaries**
```python
# Empty dictionary
customer = {}

# Dictionary with data
customer = {
    "name": "Ahmed Hassan",
    "age": 28,
    "city": "Lagos",
    "is_premium": True
}
```

**Structure:**
```python
{
    "key1": "value1",
    "key2": "value2"
}
```

---

### **Accessing Dictionary Values**
```python
customer = {
    "name": "Ahmed Hassan",
    "age": 28,
    "city": "Lagos"
}

print(customer["name"])  # "Ahmed Hassan"
print(customer["age"])   # 28

# Safer way (returns None if key doesn't exist)
print(customer.get("name"))    # "Ahmed Hassan"
print(customer.get("phone"))   # None (key doesn't exist)
```

---

### **Adding/Updating Values**
```python
customer = {"name": "Ahmed", "age": 28}

# Add new key-value pair
customer["email"] = "ahmed@email.com"

# Update existing value
customer["age"] = 29

print(customer)
# {"name": "Ahmed", "age": 29, "email": "ahmed@email.com"}
```

---

### **Removing Items**
```python
customer = {"name": "Ahmed", "age": 28, "city": "Lagos"}

# Remove specific key
del customer["city"]

# Or use pop (returns the value)
age = customer.pop("age")
print(age)  # 28

print(customer)  # {"name": "Ahmed"}
```

---

### **Dictionary Methods**
```python
customer = {"name": "Ahmed", "age": 28, "city": "Lagos"}

# Get all keys
print(customer.keys())  # dict_keys(['name', 'age', 'city'])

# Get all values
print(customer.values())  # dict_values(['Ahmed', 28, 'Lagos'])

# Get all key-value pairs
print(customer.items())  
# dict_items([('name', 'Ahmed'), ('age', 28), ('city', 'Lagos')])

# Check if key exists
print("name" in customer)  # True
print("email" in customer)  # False
```

---

### **Looping Through Dictionaries**
```python
customer = {"name": "Ahmed", "age": 28, "city": "Lagos"}

# Loop through keys
for key in customer:
    print(key)
# name
# age
# city

# Loop through values
for value in customer.values():
    print(value)
# Ahmed
# 28
# Lagos

# Loop through key-value pairs (best)
for key, value in customer.items():
    print(f"{key}: {value}")
# name: Ahmed
# age: 28
# city: Lagos
```

## Tuples

**A tuple is like a list, but immutable (cannot be changed after creation).**

**Use tuples for:** Fixed data that shouldn't change (coordinates, RGB colors, database records).

### **Creating Tuples**
```python
# Empty tuple
empty = ()

# Tuple with values
coordinates = (6.5244, 3.3792)  # Lagos coordinates
rgb_color = (255, 0, 0)  # Red color

# Single item tuple (note the comma)
single = (5,)  # Comma needed!
not_tuple = (5)  # This is just an int in parentheses
```

---

### **Accessing Tuple Items**

**Same as lists (indexing):**
```python
coordinates = (6.5244, 3.3792)
print(coordinates[0])  # 6.5244 (latitude)
print(coordinates[1])  # 3.3792 (longitude)
```

---

### **Tuples are Immutable**

**Cannot change items after creation:**
```python
coordinates = (6.5244, 3.3792)
coordinates[0] = 7.0  # ❌ Error: tuples don't support item assignment

# To "change" a tuple, create a new one
coordinates = (7.0, 3.3792)  # ✅ New tuple
```

---

### **Why Use Tuples?**

**1. Protect data from accidental changes:**
```python
# Database connection settings (shouldn't change)
db_config = ("localhost", 5432, "postgres")
```

**2. Dictionary keys (lists can't be keys, tuples can):**
```python
# Map coordinates to city names
cities = {
    (6.5244, 3.3792): "Lagos",
    (9.0579, 7.4951): "Abuja"
}
```

**3. Return multiple values from functions:**
```python
def get_min_max(numbers):
    return min(numbers), max(numbers)  # Returns a tuple

result = get_min_max([10, 5, 20, 15])
print(result)  # (5, 20)
```

## Comparing Data Structures

| Feature | List | Dictionary | Tuple |  Set  |
|---------|------|------------|-------|-------
| **Syntax** | `[1, 2, 3]` | `{"key": "value"}` | `(1, 2, 3)` |
| **Ordered?** | Yes | Yes (Python 3.7+) | Yes |
| **Mutable?** | Yes | Yes | No |
| **Duplicates?** | Yes | Keys must be unique | Yes |
| **Access by** | Index (0, 1, 2...) | Key | Index (0, 1, 2...) |
| **Use for** | Ordered collections | Key-value mappings | Fixed data |

## Real-World Data Engineering Examples

### **Example 1: Customer List**
```python
customers = [
    {"name": "Ahmed", "city": "Lagos", "total_spent": 50000},
    {"name": "Chioma", "city": "Abuja", "total_spent": 75000},
    {"name": "Emeka", "city": "Lagos", "total_spent": 30000}
]

# Find Lagos customers
for customer in customers:
    if customer["city"] == "Lagos":
        print(customer["name"])
# Ahmed
# Emeka
```

---

### **Example 2: Product Inventory**
```python
inventory = {
    "laptop": 10,
    "mouse": 50,
    "keyboard": 30
}

# Check stock
product = "laptop"
if inventory[product] > 0:
    print(f"{product} is in stock: {inventory[product]} units")
else:
    print(f"{product} is out of stock")
```

---

### **Example 3: Database Row (Tuple)**
```python
# Imagine you query a database and get a row as a tuple
customer_row = (101, "Ahmed Hassan", "ahmed@email.com", "Lagos")

# Unpack the tuple
customer_id, name, email, city = customer_row

print(f"Customer {customer_id}: {name} from {city}")
# Customer 101: Ahmed Hassan from Lagos
```

## Key Takeaways

✅ **Lists** - Ordered, mutable collections: `[1, 2, 3]`  
✅ **Dictionaries** - Key-value pairs: `{"name": "Ahmed"}`  
✅ **Tuples** - Immutable ordered collections: `(1, 2, 3)`  
✅ **Indexing** - Access items with `[0]`, `[1]`, `[-1]`  
✅ **Use lists** for collections that change  
✅ **Use dictionaries** for labeled data  
✅ **Use tuples** for fixed data  
✅ **Use Sets** for unique data
