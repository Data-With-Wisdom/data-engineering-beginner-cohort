# Lesson 4.2: Comments, Variables, Data Types, and Operators

## Comments in Python

**Comments are notes in your code that Python ignores.**

**Why use comments?**
- Explain what your code does
- Help you remember your logic later
- Help others understand your code
- Temporarily disable code

---

## Types of Comments

### **1. Single-Line Comments**

Use `#` for comments on one line:
```python
# This is a single-line comment
print("Hello")  # Comment after code

# Calculate total with VAT
total = price * 1.075
```

---

### **2. Multi-Line Comments**

Use triple quotes `"""..."""` for longer explanations:
```python
"""
This is a multi-line comment.
Use it for longer explanations.
Good for documenting what a script does.
"""

print("Hello")
```

---

### **3. Commenting Out Code**

Disable code temporarily:
```python
print("This runs")
# print("This doesn't run")
print("This runs too")
```

---

**Best Practice:** Comment the WHY, not the WHAT.
```python
# ✅ Good: Explains why
# Remove duplicates to avoid double-counting
customers = list(set(customers))

# ❌ Bad: States the obvious
# Add 2 and 2
result = 2 + 2
```

## Variables

**Variables store data.**

Think of variables as labeled boxes that hold values.
```python
name = "Ahmed"
age = 25
city = "Lagos"
is_boy = False
```

---

### **Creating Variables**

**Syntax:** `variable_name = value`
```python
customer_name = "Chioma"
order_total = 50000
is_active = True
```

**Key points:**
- Use `=` to assign values
- No need to declare type (Python figures it out)
- Variables can change

---

### **Variable Naming Rules**

✅ **Valid:**
```python
name = "Ahmed"
customer_id = 101 # _name
first_name = "Tunde"  # snake_case (Python style)
_temp = 10 # can start with an underscore
```

❌ **Invalid:**
```python
2name = "Ahmed"      # Can't start with number
first-name = "Tunde" # No hyphens
first name = "Emeka" # No spaces
@name = 78 # can't start a variable name with any special character
```

**Python convention:** Use `snake_case` for variables (lowercase with underscores).

## Data Types

**Data types define what kind of data a variable holds.**

---

### **1. Integers (int)**

Whole numbers with no decimals:
```python
age = 25
just_number = -23
customer_id = 101
year = 2024
```

---

### **2. Floats (float)**

Numbers with decimals:
```python
price = -1.22222222222222
temperature = 36.5
vat_rate = 0.075
```

---

### **3. Strings (str)**

Text data (use quotes):
```python
name = "0803823848"
city = 'Lagos'  # Single or double quotes work
message = "Hello, World!"
tripple_quotes_str = """
    jsdksdksdksdksdksdksd
"""
```

---

### **4. Booleans (bool)**

True or False values:
```python
is_active = True
is_deleted = False

```

**Note:** Must be capitalized: `True` and `False`

---

### **5. NoneType**
Used to represent an empty value in python:
```python
age = None
is_empty = None

```
**Note:** 'N' Must be capitalized

---

### **Checking Types**

Use `type()` to check a variable's type:
```python
age = 25
print(type(age))  # <class 'int'>

price = 99.99
print(type(price))  # <class 'float'>

name = "Ahmed"
print(type(name))  # <class 'str'>
```

---

### **Type Conversion**

Convert between types:
```python
# String to integer
age = int("25")
print(age + 5)  # 30

# Integer to string
age_str = str(25)
print("Age: " + age_str)  # "Age: 25"

# String to float
price = float("99.99")
print(price * 2)  # 199.98

# Float to integer (drops decimal)
x = int(99.99)
print(x)  # 99
```

**Common mistake:**
```python
age = "25"
result = age + 5  # ❌ Error: can't add string and int

# Fix:
age = int("25")
result = age + 5  # ✅ Works: 30
```

## Operators

**Operators perform operations on variables and values.**

---

### **Arithmetic Operators**
```python
x = 10
y = 3

print(x + y)   # 13  (addition)
print(x - y)   # 7   (subtraction)
print(x * y)   # 30  (multiplication)
print(x / y)   # 3.333... (division)
print(x // y)  # 3   (integer division - no decimal)
print(x % y)   # 1   (modulus - remainder)
print(x ** y)  # 1000 (exponent - 10 to power of 3)
```

**Common uses in data work:**
```python
# Calculate total price
price = 1000
quantity = 5
total = price * quantity  # 5000

# Calculate average
numbers = [10, 20, 30, 40, 50]
average = sum(numbers) / len(numbers)  # 30.0

# Check if number is even
number = 10
is_even = (number % 2 == 0)  # True
```

---

### **Comparison Operators**

Compare values (returns True or False):
```python
x = 10
y = 5

print(x == y)  # False (equal to)
print(x != y)  # True  (not equal to)
print(x > y)   # True  (greater than)
print(x < y)   # False (less than)
print(x >= y)  # True  (greater than or equal)
print(x <= y)  # False (less than or equal)
```

**Important:** `=` assigns, `==` compares!
```python
x = 5    # Assignment: x is now 5
x == 5   # Comparison: is x equal to 5? (True)
```

---

### **Logical Operators**

Combine conditions:
```python
age = 25
city = "Lagos"

# AND - both must be True
print(age > 18 and city == "Lagos")  # True

# OR - at least one must be True
print(age > 18 or city == "Abuja")   # True

# NOT - reverses True/False
is_active = True
print(not is_active)  # False
```

**Real example:**
```python
# Check if customer qualifies for discount
age = 65
is_student = False

qualifies = age >= 60 or is_student  # True (senior discount)
```

---

### **Assignment Operators**

Shortcuts for updating variables:
```python
x = 10

x = x + 5   # Long way
x += 5      # Short way (same result)

# Other shortcuts:
x -= 3   # x = x - 3
x *= 2   # x = x * 2
x /= 4   # x = x / 4
```

**Example:**
```python
total = 0
total += 100  # Add 100 (total is now 100)
total += 50   # Add 50  (total is now 150)
print(total)  # 150
```

## String Operations

**Concatenation (joining strings):**
```python
first_name = "Ahmed"
last_name = "Hassan"

full_name = first_name + " " + last_name
print(full_name)  # "Ahmed Hassan"
```

**String repetition:**
```python
print("Ha" * 3)  # "HaHaHa"
print("=" * 20)  # "===================="
```

**String formatting (f-strings):**
```python
name = "Chioma"
age = 28
city = "Lagos"

# Old way:
message = "My name is " + name + " and I am " + str(age)

# Better way (f-strings):
message = f"My name is {name} and I am {age} years old"
print(message)  # "My name is Chioma and I am 28 years old"

# With calculations:
price = 1000
print(f"Total with VAT: {price * 1.075}")  # "Total with VAT: 1075.0"
```

## Common Mistakes to Avoid

### **1. Wrong variable name case**
```python
Name = "Ahmed"
print(name)  # ❌ Error: 'name' not defined (lowercase n)
```

### **2. Forgetting quotes for strings**
```python
name = Ahmed  # ❌ Error: Ahmed not defined
name = "Ahmed"  # ✅ Correct
```

### **3. Mixing types in operations**
```python
age = "25"
result = age + 5  # ❌ Error: can't add string and int
```

### **4. Using = instead of ==**
```python
x = 5
if x = 5:  # ❌ Error: use == for comparison
    print("Yes")

if x == 5:  # ✅ Correct
    print("Yes")
```
