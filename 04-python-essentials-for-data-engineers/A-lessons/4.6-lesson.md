# Lesson 4.6: File Handling (CSV, JSON)

## Why File Handling Matters for Data Engineers

**Data engineers constantly work with files:**
- 📁 Extract data from CSV/JSON files
- 💾 Save processed data to files
- 🔄 Transform data between formats
- 📤 Export results for analysts

**Most common file formats in data work:**
- **CSV** (Comma-Separated Values) - Spreadsheet-like data
- **JSON** (JavaScript Object Notation) - Nested/structured data

---

## Working with CSV Files

**CSV files store tabular data (like Excel, but simpler).**

**Example CSV file (`customers.csv`):**
```csv
customer_id,name,email,city
1,Ahmed Hassan,ahmed@email.com,Lagos
2,Chioma Obi,chioma@email.com,Abuja
3,Emeka Nwosu,emeka@email.com,Lagos
```

---

## Reading CSV Files

### **Method 1: Using csv Module (Built-in)**
```python
import csv

# Open and read CSV
with open('customers.csv', 'r') as file:
    csv_reader = csv.reader(file)
    
    # Skip header row
    header = next(csv_reader)
    print(f"Columns: {header}")
    
    # Read each row
    for row in csv_reader:
        print(row)

# Output:
# Columns: ['customer_id', 'name', 'email', 'city']
# ['1', 'Ahmed Hassan', 'ahmed@email.com', 'Lagos']
# ['2', 'Chioma Obi', 'chioma@email.com', 'Abuja']
# ['3', 'Emeka Nwosu', 'emeka@email.com', 'Lagos']
```

---

### **Method 2: Using DictReader (Better)**

**Returns each row as a dictionary:**
```python
import csv

with open('customers.csv', 'r') as file:
    csv_reader = csv.DictReader(file)
    
    for row in csv_reader:
        print(f"Name: {row['name']}, City: {row['city']}")

# Output:
# Name: Ahmed Hassan, City: Lagos
# Name: Chioma Obi, City: Abuja
# Name: Emeka Nwosu, City: Lagos
```

**Why DictReader is better:**
- Access columns by name (more readable)
- Less error-prone
- Professional approach

---

## Writing CSV Files

### **Method 1: Using csv.writer**
```python
import csv

data = [
    ['customer_id', 'name', 'city'],
    [1, 'Ahmed Hassan', 'Lagos'],
    [2, 'Chioma Obi', 'Abuja']
]

with open('output.csv', 'w', newline='') as file:
    csv_writer = csv.writer(file)
    csv_writer.writerows(data)

print("CSV file created!")
```

**Note:** `newline=''` prevents extra blank lines on Windows.

---

### **Method 2: Using DictWriter (Better)**
```python
import csv

customers = [
    {'customer_id': 1, 'name': 'Ahmed Hassan', 'city': 'Lagos'},
    {'customer_id': 2, 'name': 'Chioma Obi', 'city': 'Abuja'}
]

with open('customers_out.csv', 'w', newline='') as file:
    fieldnames = ['customer_id', 'name', 'city']
    csv_writer = csv.DictWriter(file, fieldnames=fieldnames)
    
    csv_writer.writeheader()  # Write column names
    csv_writer.writerows(customers)  # Write data

print("CSV file created!")
```

## Real-World CSV Example: Data Cleaning
```python
import csv

# Read messy data
with open('../0-data/source/customers.csv', 'r') as infile:
    reader = csv.DictReader(infile)
    
    cleaned_data = []
    for row in reader:
        # Clean the data
        cleaned_row = {
            'customer_id': row['customer_id'],
            'name': row['name'].strip().title(),  # Remove spaces, capitalize
            'email': row['email'].lower(),  # Lowercase email
            'city': row['city'].strip()
        } 
        cleaned_data.append(cleaned_row)

# Write cleaned data
with open('cleaned_customers.csv', 'w', newline='') as outfile:
    fieldnames = ['customer_id', 'name', 'email', 'city']
    writer = csv.DictWriter(outfile, fieldnames=fieldnames)
    
    writer.writeheader()
    writer.writerows(cleaned_data)

print(f"Cleaned {len(cleaned_data)} records")
```

## Working with JSON Files

**JSON stores structured data (nested dictionaries and lists).**

**Example JSON file (`customer.json`):**
```json
{
  "customer_id": 101,
  "name": "Ahmed Hassan",
  "email": "ahmed@email.com",
  "orders": [
    {"order_id": 1001, "amount": 5000},
    {"order_id": 1002, "amount": 7500}
  ]
}
```

---

## Reading JSON Files
```python
import json

# Read JSON file
with open('customer.json', 'r') as file:
    data = json.load(file)

print(data['name'])  # Ahmed Hassan
print(data['orders'][0]['amount'])  # 5000

# Access nested data
for order in data['orders']:
    print(f"Order {order['order_id']}: ₦{order['amount']}")

# Output:
# Order 1001: ₦5000
# Order 1002: ₦7500
```

---

## Writing JSON Files
```python
import json

customer = {
    "customer_id": 102,
    "name": "Chioma Obi",
    "email": "chioma@email.com",
    "city": "Abuja",
    "orders": [
        {"order_id": 2001, "amount": 12000},
        {"order_id": 2002, "amount": 8500}
    ]
}

# Write to JSON file
with open('customer_out.json', 'w') as file:
    json.dump(customer, file, indent=4)

print("JSON file created!")
```

**`indent=4`** makes the JSON file readable (pretty-printed).

**Output file:**
```json
{
    "customer_id": 102,
    "name": "Chioma Obi",
    "email": "chioma@email.com",
    "city": "Abuja",
    "orders": [
        {
            "order_id": 2001,
            "amount": 12000
        },
        {
            "order_id": 2002,
            "amount": 8500
        }
    ]
}
```

## JSON with Lists (Multiple Records)

**Common pattern: List of dictionaries**

**Example (`customers.json`):**
```json
[
  {"customer_id": 1, "name": "Ahmed", "city": "Lagos"},
  {"customer_id": 2, "name": "Chioma", "city": "Abuja"},
  {"customer_id": 3, "name": "Emeka", "city": "Lagos"}
]
```

**Reading:**
```python
import json

with open('customers.json', 'r') as file:
    customers = json.load(file)

# Loop through customers
for customer in customers:
    print(f"{customer['name']} from {customer['city']}")

# Filter Lagos customers
lagos_customers = [c for c in customers if c['city'] == 'Lagos']
print(f"Lagos customers: {len(lagos_customers)}")
```

**Writing:**
```python
import json

customers = [
    {"customer_id": 1, "name": "Ahmed", "city": "Lagos"},
    {"customer_id": 2, "name": "Chioma", "city": "Abuja"}
]

with open('customers_out.json', 'w') as file:
    json.dump(customers, file, indent=2)
```

## Converting Between CSV and JSON

### **CSV to JSON**
```python
import csv
import json 

# Read CSV
with open('customers.csv', 'r') as csv_file:
    csv_reader = csv.DictReader(csv_file)
    customers = list(csv_reader)

# Write JSON
with open('customers.json', 'w') as json_file:
    json.dump(customers, json_file, indent=2)

print("Converted CSV to JSON")
```

---

### **JSON to CSV**
```python
import csv
import json

# Read JSON
with open('customers.json', 'r') as json_file:
    customers = json.load(json_file)

# Write CSV
with open('customers.csv', 'w', newline='') as csv_file:
    fieldnames = customers[0].keys()  # Get column names from first record
    writer = csv.DictWriter(csv_file, fieldnames=fieldnames)
    
    writer.writeheader()
    writer.writerows(customers)

print("Converted JSON to CSV")
```

## File Paths

### **Absolute vs Relative Paths**

**Absolute path (full path from root):**
```python
file = open('/Users/ahmed/data/customers.csv', 'r')  # Mac/Linux
file = open('C:\\Users\\ahmed\\data\\customers.csv', 'r')  # Windows
```


**Relative path (from current directory):**
```python
file = open('customers.csv', 'r')  # Same folder
file = open('data/customers.csv', 'r')  # In 'data' subfolder
file = open('../0-data/source/customers.csv', 'r')  # Parent folder
```

**Best practice:** Use relative paths (more portable).

## Real-World Data Pipeline Example

**Task:** Read sales data, clean it, calculate totals, save results.
```python
import csv
import json

# Step 1: Read CSV
with open('sales.csv', 'r') as file:
    reader = csv.DictReader(file)
    sales = list(reader)

# Step 2: Clean and transform
cleaned_sales = []
for sale in sales:
    # Convert strings to numbers
    cleaned = {
        'product': sale['product'].strip(),
        'quantity': int(sale['quantity']),
        'price': float(sale['price']),
        'total': int(sale['quantity']) * float(sale['price'])
    }
    cleaned_sales.append(cleaned)

# Step 3: Calculate summary
total_revenue = sum(sale['total'] for sale in cleaned_sales)
summary = {
    'total_sales': len(cleaned_sales),
    'total_revenue': total_revenue,
    'average_sale': total_revenue / len(cleaned_sales)
}

# Step 4: Save results
# Save cleaned data as CSV
with open('sales_cleaned.csv', 'w', newline='') as file:
    fieldnames = ['product', 'quantity', 'price', 'total']
    writer = csv.DictWriter(file, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerows(cleaned_sales)

# Save summary as JSON
with open('sales_summary.json', 'w') as file:
    json.dump(summary, file, indent=2)

print("Pipeline complete!")
print(f"Processed {summary['total_sales']} sales")
print(f"Total revenue: ₦{summary['total_revenue']}")
```

## Key Takeaways

✅ **CSV** - Use `csv.DictReader` and `csv.DictWriter`  
✅ **JSON** - Use `json.load()` and `json.dump()`  
✅ **with open()** - Always use context manager (auto-closes files)  
✅ **Read mode** - `'r'` for reading  
✅ **Write mode** - `'w'` for writing (overwrites existing)  
✅ **Append mode** - `'a'` for appending  
✅ **Convert formats** - CSV ↔ JSON for different use cases
