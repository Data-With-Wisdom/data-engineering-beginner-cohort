# Lesson 4.5: Functions

## What are Functions?

**A function is a reusable block of code that performs a specific task.**

**Why use functions?**
- ♻️ **Reusability** - Write once, use many times
- 📦 **Organization** - Break code into logical pieces
- 🐛 **Easier debugging** - Fix one function instead of duplicating code
- 📖 **Readability** - Makes code easier to understand

**Think of functions as:** Recipes in a cookbook - follow the recipe (function) to get the result.

---

Python comes with many built-in functions:

## Creating Your Own Functions

### **Basic Syntax**
```python
def function_name():
    # Code block
    print("This is a function")
```

**Example:**
```python
def greet():
    print("Hello, World!")

# Call the function
greet()  # Output: Hello, World!
```

**Key parts:**
- `def` - Define a function
- `function_name` - Name of the function (use snake_case)
- `()` - Parentheses (parameters go here, if any)
- `:` - Colon to start the function block
- Indented code - The function body

---

## Functions with Parameters

**Parameters let you pass data into functions.**
```python
def greet(name):
    print(f"Hello, {name}!")

greet("Ahmed")   # Hello, Ahmed!
greet("Chioma")  # Hello, Chioma!
```

---

### **Multiple Parameters**
```python
def calculate_total(price, quantity):
    total = price * quantity
    print(f"Total: ₦{total}")

calculate_total(1000, 5)  # Total: ₦5000
calculate_total(2500, 3)  # Total: ₦7500
```

---

### **Default Parameters**

**Provide default values:**
```python
def greet(name="Guest"):
    print(f"Hello, {name}!")

greet("Ahmed")  # Hello, Ahmed!
greet()         # Hello, Guest! (uses default)
```

**Example with multiple defaults:**
```python
def calculate_price(price, tax_rate=0.075, discount=0):
    total = price * (1 + tax_rate) - discount
    return total

print(calculate_price(1000))              # Uses default tax and discount
print(calculate_price(1000, 0.10))        # Custom tax rate
print(calculate_price(1000, 0.075, 100))  # Custom tax and discount
```

## Return Values

**Functions can return results instead of printing.**
```python
def add(a, b):
    return a + b

result = add(10, 5)
print(result)  # 15
```

**Why return instead of print?**
- You can use the result in calculations
- More flexible
- Professional coding practice

---

### **Return vs Print**
```python
# With print (not reusable)
def add_print(a, b):
    print(a + b)

add_print(10, 5)  # 15
result = add_print(10, 5)  # 15
print(result)  # None (function doesn't return anything)

# With return (reusable)
def add_return(a, b):
    return a + b

result = add_return(10, 5)
print(result)  # 15
print(result * 2)  # 30 (can use the result)
```

---

### **Return Multiple Values**
```python
def get_min_max(numbers):
    return min(numbers), max(numbers)

minimum, maximum = get_min_max([10, 5, 20, 15])
print(f"Min: {minimum}, Max: {maximum}")  # Min: 5, Max: 20
```

## Real-World Data Engineering Functions

### **Example 1: Data Cleaning**
```python
def clean_phone_number(phone):
    # Remove spaces and hyphens
    cleaned = phone.replace(" ", "").replace("-", "")
    return cleaned

phone1 = clean_phone_number("080-1234-5678")
phone2 = clean_phone_number("070 9876 5432")

print(phone1)  # 08012345678
print(phone2)  # 07098765432
```

---

### **Example 2: Data Validation**
```python
def is_valid_email(email):
    if "@" in email and "." in email:
        return True
    else:
        return False

print(is_valid_email("ahmed@email.com"))  # True
print(is_valid_email("invalid-email"))    # False
```

---

### **Example 3: Calculate Metrics**
```python
def calculate_average(numbers):
    if len(numbers) == 0:
        return 0
    total = sum(numbers)
    average = total / len(numbers)
    return average

sales = [1000, 2500, 1500, 3000]
avg = calculate_average(sales)
print(f"Average sale: ₦{avg}")  # Average sale: ₦2000.0
```

---

### **Example 4: Transform Data**
```python
def convert_to_uppercase(items):
    result = []
    for item in items:
        result.append(item.upper())
    return result

cities = ["lagos", "abuja", "kano"]
uppercase_cities = convert_to_uppercase(cities)
print(uppercase_cities)  # ["LAGOS", "ABUJA", "KANO"]
```

## Function Scope

**Variables inside functions are local (only exist inside the function).**
```python
def my_function():
    local_var = "I'm local"
    print(local_var)

my_function()  # I'm local
print(local_var)  # ❌ Error: local_var is not defined
```

**Global vs Local:**
```python
global_var = "I'm global"

def my_function():
    local_var = "I'm local"
    print(global_var)  # Can access global
    print(local_var)   # Can access local

my_function()
print(global_var)  # ✅ Works
print(local_var)   # ❌ Error
```

## Docstrings (Function Documentation)

**Use docstrings to explain what a function does:**
```python
def calculate_vat(amount, rate=0.075):
    """
    Calculate VAT (Value Added Tax) on an amount.
    
    Parameters:
    amount (float): The base amount
    rate (float): VAT rate (default 0.075 for 7.5%)
    
    Returns:
    float: The VAT amount
    """
    return amount * rate

# Access docstring
print(calculate_vat.__doc__)
```

**Good practice:** Always document your functions, especially in data engineering work.
