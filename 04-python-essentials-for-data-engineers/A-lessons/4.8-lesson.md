# Lesson 4.8: Error Handling

## Why Error Handling Matters

**Things will go wrong:**
- 📁 Files might not exist
- 🔢 Users might enter text instead of numbers
- 🌐 APIs might be down
- 💾 Databases might be unavailable

**Without error handling:**
- Your program crashes
- You lose all progress
- Users see cryptic error messages

**With error handling:**
- Your program continues running
- You log the error for debugging
- Users see helpful messages

---

## Common Python Errors

### **1. SyntaxError - Code is written incorrectly**
```python
# Missing colon
if age > 18  # ❌ SyntaxError: invalid syntax
    print("Adult")

# Fix:
if age > 18:  # ✅
    print("Adult")
```

---

### **2. NameError - Variable doesn't exist**
```python
print(name)  # ❌ NameError: name 'name' is not defined

# Fix: Define the variable first
name = "Ahmed"
print(name)  # ✅
```

---

### **3. TypeError - Wrong data type for operation**
```python
age = "25"
result = age + 5  # ❌ TypeError: can only concatenate str to str

# Fix: Convert type
age = int("25")
result = age + 5  # ✅ 30
```

---

### **4. ValueError - Right type, wrong value**
```python
age = int("twenty")  # ❌ ValueError: invalid literal for int()

# Fix: Validate input
age_str = "twenty"
if age_str.isdigit():
    age = int(age_str)
else:
    print("Please enter a number")  # ✅
```

---

### **5. FileNotFoundError - File doesn't exist**
```python
file = open('missing.csv', 'r')  # ❌ FileNotFoundError

# Fix: Check if file exists
import os
if os.path.exists('missing.csv'):
    file = open('missing.csv', 'r')
else:
    print("File not found")  # ✅
```

---

### **6. IndexError - List index out of range**
```python
numbers = [10, 20, 30]
print(numbers[5])  # ❌ IndexError: list index out of range

# Fix: Check length
if len(numbers) > 5:
    print(numbers[5])
else:
    print("Index doesn't exist")  # ✅
```

---

### **7. KeyError - Dictionary key doesn't exist**
```python
customer = {"name": "Ahmed", "age": 28}
print(customer["email"])  # ❌ KeyError: 'email'

# Fix: Use .get() or check if key exists
email = customer.get("email", "No email")  # ✅ Returns "No email"
# Or:
if "email" in customer:
    print(customer["email"])
else:
    print("No email")  # ✅
```

---

### **8. ZeroDivisionError - Dividing by zero**
```python
result = 10 / 0  # ❌ ZeroDivisionError

# Fix: Check before dividing
divisor = 0
if divisor != 0:
    result = 10 / divisor
else:
    print("Cannot divide by zero")  # ✅
```

## try-except: Catching Errors

**try-except lets your program handle errors gracefully.**

### **Basic Syntax**
```python
try:
    # Code that might cause an error
    risky_code()
except:
    # Code that runs if an error occurs
    print("An error occurred")
```

---

### **Example 1: Handle Any Error**
```python
try:
    age = int(input("Enter your age: "))
    print(f"You are {age} years old")
except:
    print("Invalid input. Please enter a number.")
```

---

### **Example 2: Catch Specific Errors**
```python
try:
    age = int(input("Enter your age: "))
    print(f"You are {age} years old")
except ValueError:
    print("Please enter a valid number")
except KeyboardInterrupt:
    print("\nProgram cancelled by user")
```

---

### **Example 3: Multiple Except Blocks**
```python
try:
    numbers = [10, 20, 30]
    index = int(input("Enter index: "))
    print(numbers[index])
except ValueError:
    print("Index must be a number")
except IndexError:
    print("Index out of range")
except Exception as e:
    print(f"An error occurred: {e}")
```

---

## else and finally

### **else - Runs if NO error occurs**
```python
try:
    age = int(input("Enter age: "))
except ValueError:
    print("Invalid input")
else:
    print(f"You entered: {age}")  # Only runs if no error
```

---

### **finally - ALWAYS runs (error or not)**
```python
try:
    file = open('data.csv', 'r')
    data = file.read()
except FileNotFoundError:
    print("File not found")
finally:
    print("Cleanup complete")  # Always runs
```

**Common use:** Closing files or database connections.

## Real-World Data Engineering Examples

### **Example 1: Safe File Reading**
```python
def read_file_safe(filename):
    try:
        with open(filename, 'r') as file:
            return file.read()
    except FileNotFoundError:
        print(f"Error: {filename} not found")
        return None
    except PermissionError:
        print(f"Error: No permission to read {filename}")
        return None
    except Exception as e:
        print(f"Unexpected error: {e}")
        return None

# Use it
content = read_file_safe('customers.csv')
if content:
    print("File read successfully")
else:
    print("Failed to read file")
```

---

### **Example 2: Safe Type Conversion**
```python
def safe_int(value, default=0):
    try:
        return int(value)
    except (ValueError, TypeError):
        return default

# Use it
ages = ["25", "thirty", "45", None, "19"]
for age_str in ages:
    age = safe_int(age_str, default=0)
    print(f"{age_str} → {age}")

# Output:
# 25 → 25
# thirty → 0
# 45 → 45
# None → 0
# 19 → 19
```

### **Example 3: Retry Logic**
```python
def fetch_data_with_retry(max_attempts=3):
    attempt = 0
    while attempt < max_attempts:
        try:
            # Simulate API call
            data = fetch_api()  # Might fail
            return data
        except ConnectionError:
            attempt += 1
            print(f"Attempt {attempt} failed. Retrying...")
            if attempt >= max_attempts:
                print("Max retries reached. Giving up.")
                return None
```

### **Example 4: Data Validation**
```python
def validate_customer_data(customer):
    errors = []
    
    # Check name
    try:
        if not customer['name'] or len(customer['name'].strip()) == 0:
            errors.append("Name is required")
    except KeyError:
        errors.append("Name field missing")
    
    # Check email
    try:
        email = customer['email']
        if "@" not in email:
            errors.append("Invalid email format")
    except KeyError:
        errors.append("Email field missing")
    
    # Check age
    try:
        age = int(customer['age'])
        if age < 0 or age > 120:
            errors.append("Invalid age")
    except (KeyError, ValueError):
        errors.append("Age must be a valid number")
    
    return errors

# Test
customer1 = {"name": "Ahmed", "email": "ahmed@email.com", "age": "28"}
customer2 = {"name": "", "email": "invalid", "age": "two"}

print(validate_customer_data(customer1))  # []
print(validate_customer_data(customer2))  
# ['Name is required', 'Invalid email format', 'Age must be a valid number']
```

### **Example 5: CSV Processing with Error Handling**
```python
import csv

def process_csv_safe(filename):
    processed = 0
    errors = 0
    
    try:
        with open(filename, 'r') as file:
            reader = csv.DictReader(file)
            
            for row_num, row in enumerate(reader, start=2):  # start=2 (header is line 1)
                try:
                    # Validate and process each row
                    customer_id = int(row['customer_id'])
                    age = int(row['age'])
                    email = row['email'].strip()
                    
                    if "@" not in email:
                        raise ValueError("Invalid email")
                    
                    # Process the row
                    print(f"Processed customer {customer_id}")
                    processed += 1
                    
                except (ValueError, KeyError) as e:
                    print(f"Error on line {row_num}: {e}")
                    errors += 1
                    continue  # Skip this row, continue with next
        
        print(f"\nSummary: {processed} processed, {errors} errors")
        
    except FileNotFoundError:
        print(f"File {filename} not found")
    except Exception as e:
        print(f"Unexpected error: {e}")

# Use it
process_csv_safe('customers.csv')
```

## Best Practices

### **1. Be Specific with Exceptions**
```python
# ❌ Too broad
try:
    code()
except:
    pass  # What error? Who knows!

# ✅ Specific
try:
    age = int(user_input)
except ValueError:
    print("Please enter a number")
```

---

### **2. Don't Hide Errors Silently**
```python
# ❌ Bad: Errors are hidden
try:
    critical_operation()
except:
    pass  # Error is lost!

# ✅ Good: Log the error
try:
    critical_operation()
except Exception as e:
    print(f"Error occurred: {e}")
    # Or: log to file
```

---

### **3. Use finally for Cleanup**
```python
# ✅ Good: File always closes
try:
    file = open('data.csv', 'r')
    process(file)
except Exception as e:
    print(f"Error: {e}")
finally:
    file.close()  # Always closes, even if error

# Better: Use with (auto-closes)
try:
    with open('data.csv', 'r') as file:
        process(file)
except Exception as e:
    print(f"Error: {e}")
```

---

### **4. Provide Helpful Error Messages**
```python
# ❌ Vague
except ValueError:
    print("Error")

# ✅ Helpful
except ValueError as e:
    print(f"Invalid data format: {e}")
    print("Please check your input and try again")
```

---


## Key Takeaways

✅ **try-except** - Catch and handle errors gracefully  
✅ **Specific exceptions** - Catch specific errors (ValueError, FileNotFoundError, etc.)  
✅ **else** - Runs if NO error occurs  
✅ **finally** - ALWAYS runs (cleanup code)  
✅ **Don't hide errors** - Log or print them for debugging  
✅ **Provide helpful messages** - Tell users what went wrong and how to fix it  
✅ **Use error handling** in file operations, user input, API calls
