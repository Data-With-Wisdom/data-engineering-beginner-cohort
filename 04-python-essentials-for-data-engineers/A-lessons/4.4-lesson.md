# Lesson 4.4: Control Flow (if/else, loops)

## What is Control Flow?

**Control flow determines the order in which code executes.**

**Two main types:**
1. **Conditional statements (if/else)** - Make decisions
2. **Loops (for/while)** - Repeat actions

**Think of it as:** Programming instructions like "if it rains, take an umbrella" or "check every customer in the list."

---

## if Statements

**Execute code only if a condition is True.**

### **Basic Syntax**
```python
if condition:
    # Code runs if condition is True
    print("Condition is True")
```

**Example:**
```python
age = 25

if age >= 18:
    print("You are an adult")
```

**⚠️ Important:** Indentation matters! Code inside the if block must be indented (4 spaces).

---

### **Comparison Operators (Recap)**
```python
==  # Equal to
!=  # Not equal to
>   # Greater than
<   # Less than
>=  # Greater than or equal to
<=  # Less than or equal to
```

**Examples:**
```python
price = 1000

if price > 500:
    print("Expensive")

if price == 1000:
    print("Price is exactly 1000")

if price != 0:
    print("Price is not zero")
```

---

## if-else Statements

**Execute one block if True, another if False.**
```python
if condition:
    # Runs if True
else:
    # Runs if False
```

**Example:**
```python
age = 16

if age >= 18:
    print("You can vote")
else:
    print("You cannot vote yet")
```

---

## if-elif-else Statements

**Check multiple conditions.**
```python
if condition1:
    # Runs if condition1 is True
elif condition2:
    # Runs if condition1 is False and condition2 is True
else:
    # Runs if all conditions are False
```

**Example:**
```python
score = 75

if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
elif score >= 70:
    print("Grade: C")
else:
    print("Grade: F")

# Output: Grade: C
```

---

### **Real-World Example: Order Status**
```python
order_amount = 5000
customer_city = "Lagos"

if order_amount >= 10000:
    print("Free shipping!")
elif customer_city == "Lagos":
    print("Shipping: ₦500")
else:
    print("Shipping: ₦1000")

# Output: Shipping: ₦500
```

## Logical Operators

**Combine multiple conditions.**

### **and - Both conditions must be True**
```python
age = 25
city = "Lagos"

if age >= 18 and city == "Lagos":
    print("Eligible for Lagos youth program")
```

---

### **or - At least one condition must be True**
```python
payment_method = "card"

if payment_method == "card" or payment_method == "mobile_money":
    print("Payment accepted")
```

---

### **not - Reverses the condition**
```python
is_deleted = False

if not is_deleted:
    print("Customer is active")
```

---

### **Combining Multiple Conditions**
```python
age = 30
city = "Lagos"
is_premium = True

if (age >= 18 and city == "Lagos") or is_premium:
    print("Eligible for special offer")
```

**Use parentheses `()` to make logic clear.**

## for Loops

**Repeat code for each item in a sequence.**

### **Basic Syntax**
```python
for item in sequence:
    # Code runs once for each item
    print(item)
```

---

### **Loop Through a List**
```python
cities = ["Lagos", "Abuja", "Port Harcourt"]

for city in cities:
    print(city)

# Output:
# Lagos
# Abuja
# Port Harcourt
```

---

### **Loop Through a Range of Numbers**
```python
for i in range(5):
    print(i)

# Output: 0, 1, 2, 3, 4
```

**`range(start, stop, step)`:**
```python
# range(stop) - 0 to stop-1
for i in range(5):
    print(i)  # 0, 1, 2, 3, 4

# range(start, stop)
for i in range(2, 5):
    print(i)  # 2, 3, 4

# range(start, stop, step)
for i in range(0, 10, 2):
    print(i)  # 0, 2, 4, 6, 8
```

---

### **Loop Through a Dictionary**
```python
customer = {"name": "Ahmed", "age": 28, "city": "Lagos"}

# Loop through keys
for key in customer:
    print(key)

# Loop through key-value pairs
for key, value in customer.items():
    print(f"{key}: {value}")

# Output:
# name: Ahmed
# age: 28
# city: Lagos
```

---

### **Loop with Index (enumerate)**
```python
cities = ["Lagos", "Abuja", "Kano"]

for index, city in enumerate(cities):
    print(f"{index}: {city}")

# Output:
# 0: Lagos
# 1: Abuja
# 2: Kano
```

---

### **Real-World Example: Calculate Total**
```python
prices = [1000, 2500, 500, 7500]

total = 0
for price in prices:
    total += price

print(f"Total: ₦{total}")  # Total: ₦11500
```

## while Loops

**Repeat code as long as a condition is True.**

### **Basic Syntax**
```python
while condition:
    # Code runs as long as condition is True
    print("Still running")
```

**⚠️ Warning:** Make sure the condition eventually becomes False, or the loop runs forever!

---

### **Example**
```python
count = 0

while count < 5:
    print(count)
    count += 1  # Important: update count!

# Output: 0, 1, 2, 3, 4
```

---

### **Real-World Example: Retry Logic**
```python
attempts = 0
max_attempts = 3

while attempts < max_attempts:
    print(f"Attempt {attempts + 1}")
    # Simulate trying to connect to API
    attempts += 1

print("Max attempts reached")
```

## break and continue

### **break - Exit the loop early**
```python
for i in range(10):
    if i == 5:
        break  # Stop the loop
    print(i)

# Output: 0, 1, 2, 3, 4 (stops at 5)
```

---

### **continue - Skip to next iteration**
```python
for i in range(5):
    if i == 2:
        continue  # Skip this iteration
    print(i)

# Output: 0, 1, 3, 4 (skips 2)
```

---

### **Real-World Example: Process Valid Data**
```python
orders = [1000, 0, 2500, -500, 7500]

for order in orders:
    if order <= 0:
        continue  # Skip invalid orders
    print(f"Processing order: ₦{order}")

# Output:
# Processing order: ₦1000
# Processing order: ₦2500
# Processing order: ₦7500
```

## Nested Loops

**Loop inside another loop.**
```python
categories = ["Electronics", "Fashion"]
products = ["Item1", "Item2"]

for category in categories:
    for product in products:
        print(f"{category} - {product}")

# Output:
# Electronics - Item1
# Electronics - Item2
# Fashion - Item1
# Fashion - Item2
```

## Common Patterns in Data Engineering

### **Pattern 1: Filter Data**
```python
# Keep only completed orders
orders = [
    {"id": 1, "status": "completed"},
    {"id": 2, "status": "pending"},
    {"id": 3, "status": "completed"}
]

completed = []
for order in orders:
    if order["status"] == "completed":
        completed.append(order)

print(completed)
```

---

### **Pattern 2: Transform Data**
```python
# Convert prices from dollars to naira
prices_usd = [10, 25, 50]
exchange_rate = 1500

prices_ngn = []
for price in prices_usd:
    prices_ngn.append(price * exchange_rate)

print(prices_ngn)  # [15000, 37500, 75000]
```

---

### **Pattern 3: Aggregate Data**
```python
# Calculate total sales by category
sales = [
    {"category": "Electronics", "amount": 5000},
    {"category": "Fashion", "amount": 3000},
    {"category": "Electronics", "amount": 7000}
]

totals = {}
for sale in sales:
    category = sale["category"]
    amount = sale["amount"]
    
    if category in totals:
        totals[category] += amount
    else:
        totals[category] = amount

print(totals)  # {"Electronics": 12000, "Fashion": 3000}
```

## Key Takeaways

✅ **if/else** - Make decisions based on conditions  
✅ **for loops** - Repeat for each item in a collection  
✅ **while loops** - Repeat as long as condition is True  
✅ **break** - Exit loop early  
✅ **continue** - Skip to next iteration  
✅ **Indentation** - Always indent code blocks (4 spaces)  
✅ **Logical operators** - and, or, not for complex conditions
